# T!ts UUp now runs in the browser

The 2023 Weeksauce game never made it beyond its native builds, so here it is as a web page: a straight port of the VB.NET and MonoGame original to Odin and WebAssembly.

What carried over: the 9x9 room, the twelve goblins, the key and the locked door, dice that only count on a six, the gear that wears out, the dignity score, the five save slots and the same 320x180 screen with the same tiles and font.

What changed: saves and the volume setting live in the browser's local storage, there is no window-size option or quit button (it is a tab now), and there are on-screen buttons for phones.

The port was written with Claude Code at my direction, and the original's rules were read from its source, not guessed.
